# AudioMass

無料のフル機能Webベースオーディオ&ウェーブフォームエディティングツールです。

## デモ
[https://audiomass.co](https://audiomass.co)

## 機能
- フルスクリーンウェーブフォームエディター
- 基本的な編集ツール (切り取り、コピー、ペースト、ズーム、スクロールなど)
- スピーカー/ヘッドフォン再生
- 対応オーディオフォーマット: MP3、WAV、FLAC、AIFF
- ID3タグ編集
- イコライザー
- 自動音量調整
- 録音機能
- 操作履歴(Undo/Redo)
- プリセット機能

## 使い方
1. このリポジトリをチェックアウトするか (または、zipファイルをダウンロードする)
2. お気に入りのCLIからそのディレクトリに移動し、`src`ディレクトリにアクセスする
3. `go run audiomass-server.go`を実行する - または、Golangがインストールされていない場合は、`python audiomass-server.py`を使ってシンプルなPythonウェブサーバーを使用できます
4. [http://localhost:5055/](http://localhost:5055/)にナビゲートして、楽しみましょう!
