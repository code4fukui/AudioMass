# AudioMass

無料かつオープンソースで開発されている、Webベースの多機能オーディオ＆波形編集ツールです。ブラウザのみで動作し、プラグインやバックエンドサーバーは不要です。

## デモ

実際にブラウザで試すことができます。
[https://audiomass.co](https://audiomass.co)

## 主な機能

-   **視覚的な波形編集**: ズーム、スクロール、選択などの操作が可能なフル機能の波形エディタ。
-   **基本的な編集機能**: カット、コピー、ペースト、トリムなど、基本的なオーディオ編集操作に対応。
-   **オーディオエフェクト**: ゲイン（音量）調整、速度変更、イコライザー、チャンネル反転など、多数のエフェクトを搭載。
-   **フォーマット対応**: MP3, WAV, FLAC, OGG, AIFFなど、ブラウザがサポートする多くのオーディオ形式を読み込み可能。
-   **エクスポート**: 編集したオーディオをMP3またはWAV形式でダウンロード。ビットレートやチャンネル（モノラル/ステレオ）の指定も可能です。
-   **マイク録音**: ブラウザを通じて直接音声を録音し、編集できます。
-   **操作履歴**: Undo/Redo機能により、編集内容を元に戻したりやり直したりできます。
-   **プリセット管理**: エフェクトの設定をカスタムプリセットとして保存・再利用できます。
-   **ID3タグ編集**: MP3ファイルなどのメタデータを編集できます。
-   **ローカルセッション保存**: 編集中のセッションをブラウザのIndexedDBに保存し、後で作業を再開できます。
-   **オフライン対応**: Service Workerにより、一度読み込むとオフラインでも動作します。

## 使い方

1.  このリポジトリをクローンするか、zipファイルとしてダウンロードします。
2.  ターミナルでお好みのCLIを使い、`src`ディレクトリに移動します。
3.  `go run audiomass-server.go`を実行します。Golangがインストールされていない場合は、`python audiomass-server.py`でシンプルなPythonウェブサーバーを利用することもできます。
4.  ブラウザで [http://localhost:5055/](http://localhost:5055/) を開き、利用を開始します。
