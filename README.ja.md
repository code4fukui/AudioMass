# AudioMass

無料でオープンソースの、ウェブベースのオーディオおよび波形エディタです。バックエンドやプラグインは不要で、すべてブラウザ上で動作します。

## ライブデモ

[https://audiomass.co](https://audiomass.co)

## スクリーンショット

![AudioMass Interface](https://user-images.githubusercontent.com/127535/235270115-1135b85e-2e5a-4252-8791-d327827b21fc.jpg)

*メインエディタの画面。波形と、フローティングおよびドッキング可能な周波数アナライザ（Frequency Analyser）パネルが表示されています。*

## 機能

*   **編集:** カット、コピー、ペースト、トリム、ズームを備えた、高速でレスポンシブな波形編集。
*   **エフェクト:** ゲイン、フェードイン/アウト、反転、逆再生、スピード変更、パラメトリックEQなどのエフェクトスイート。
*   **オートメーション:** オートメーションポイントを使用して、時間経過とともに段階的なエフェクトを適用。
*   **対応フォーマット:** MP3、WAV、FLAC、OGG、AIFFファイルの読み込みとエクスポート。
*   **分析:** オーディオの周波数スペクトル分析を表示。
*   **モダンなUI:** ドッキング可能なパネルを備え、柔軟でカスタマイズ可能なユーザーインターフェース。
*   **セッション管理:** セッションはブラウザのIndexedDBに保存され、LZ4圧縮により高速かつ効率的に処理されます。
*   **ワークフロー:** ドラッグ＆ドロップによるファイル読み込みと、堅牢なアンドゥ/リドゥ履歴。
*   **録音:** マイクから直接オーディオを録音。

## 要件

*   モダンなウェブブラウザ（Chrome、Firefox、Safariを推奨）。
*   ローカル開発の場合: Go (1.18+) または Python 3。

## はじめに

1.  このリポジトリをクローンするか、ZIPファイルとしてダウンロードします。
2.  コマンドラインで `src` ディレクトリに移動します。
    ```sh
    cd AudioMass/src
    ```
3.  ローカル開発サーバーを実行します。
    *   **Goを使用する場合:**
        ```sh
        go run audiomass-server.go
        ```
    *   **または、Pythonを使用する場合:**
        ```sh
        python audiomass-server.py
        ```
4.  ブラウザを開き、[http://localhost:5055/](http://localhost:5055/) にアクセスします。
